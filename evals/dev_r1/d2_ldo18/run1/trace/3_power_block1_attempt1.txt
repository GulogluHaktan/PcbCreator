BLOCK: linear_regulator: Fixed 1.8V low-dropout linear regulator. Include its input and output capacitors and tie any enable pin as the datasheet card says in this block.

REASONING
The SPX3819M5-L-1-8 is a fixed 1.8V LDO regulator. Pin 1 (IN) connects to VIN, Pin 2 (GND) to GND, Pin 5 (OUT) to VOUT. Pin 3 (EN) is the enable pin; per typical LDO datasheets, if not specified otherwise, it should be tied to the input rail (VIN) to enable regulation. Pin 4 (BP) is a bypass pin; if unused, it should be left unconnected (NC). A 100nF decoupling capacitor is required on the output pin (Pin 5) to GND. An input capacitor is also recommended for stability; a 1uF capacitor from VIN to GND is standard. The output capacitor (100nF) is placed between VOUT and GND. The LED is yellow, connected to VOUT, with a series resistor to limit current to ~1mA. Assuming a typical yellow LED forward voltage of 2.0V, the resistor value is (1.8V - 2.0V) which is negative, so we must assume a lower Vf or adjust. However, the constraint says LED current must be approximately 1mA and connected to 1.8V rail. A typical yellow LED has Vf ~1.8-2.0V. If Vf=1.8V, then R=(1.8-1.8)/0.001=0, which is not practical. If we assume Vf=1.5V (some yellow LEDs), R=(1.8-1.5)/0.001=300 ohms. But standard yellow LEDs are often 2.0V. However, the problem says
